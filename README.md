# Çay Kaşığı Anayasa Mahkemesi

Bu depo bir şakadır. Aynı zamanda değildir. Mahkeme kurulmuştur.

## Görev

Çay bardağının içinde unutulan metal kaşığın, çayın egemenliğini ihlal edip etmediğine bakmak. Karar bağlayıcıdır. Kimse uymaz. Çay yine soğur.

Bu kurum;

- hiçbir bakanlığa bağlı değildir,
- şeker oranına karışmaz,
- ince belliye saygı duyar,
- patatesi tanımaz, kapıdan çevirir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Çay isteğe bağlıdır, tavsiye edilir, mahkeme salonuna dökülmesi yasaktır.

```bash
python3 mahkeme.py
python3 mahkeme.py --iddia "Kaşık hep sağa yaslanıyor" --tur 5
python3 mahkeme.py --gizli-tutanak
```

`--gizli-tutanak` bayrağı resmi evrak değildir. Kimse okumasın. Okuyan da unutsun.

## İçtihat

1. Kaşık kalabilir.
2. Kaşık çıkabilir.
3. Mahkeme çekimser kalıp terleyebilir.

Üçü de geçerlidir. İstinaf, çaydanlığın kapağının altındadır.

## Dosya düzeni

- `mahkeme.py` — çalışan duruşma.
- `tutanak/arsiv.b64` — arşiv. Arşiv arşivdir.
- `YEMIN.txt` — bardak yemin etti, kaşık yemin etmedi.

## Lisans

Çay içildiği sürece serbest. Dökülürse telif kaşığa geçer.
